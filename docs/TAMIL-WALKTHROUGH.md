# 🏭 உள்நுழைவு → டாஷ்போர்டு — முழு விளக்கம் (தமிழில்)

KAK TEXTILE PROCESSING ERP — உள்நுழைவுப் பக்கத்தில் தொடங்கி டாஷ்போர்டு வரை
ஒவ்வொரு வரியாக என்ன செய்கிறது என்பதன் விளக்கம். (பொது வெப்சைட் நீக்கப்பட்டது —
இப்போது நேரடியாக ஊழியர் உள்நுழைவுப் பக்கம் மட்டுமே.)

## ⚙️ பகுதி 2: "Sign In to ERP" அழுத்திய பின் பின்னணியில் நடப்பவை

1. பயனர்பெயரும் கடவுச்சொல்லும் சர்வருக்கு அனுப்பப்படும்.
2. சர்வர் கடவுச்சொல்லின் சரியான தன்மையைச் சரிபார்க்கும்.
3. சரியெனில் ஒரு பாதுகாப்பு டோக்கன் (JWT) வழங்கப்படும்.
4. அந்த டோக்கன் உலாவியில் (browser) சேமிக்கப்படும்.
5. அதற்குப் பிறகு ஒவ்வொரு பக்கமும் அந்த டோக்கன் இருந்தால் மட்டுமே திறக்கும் — இதுவே பாதுகாப்பு.
6. உடனே டாஷ்போர்டு பக்கத்திற்கு மாற்றப்படுவீர்கள்.

## 📊 பகுதி 3: டாஷ்போர்டு (உள்நுழைந்த பின் முதல் பக்கம்)

| வரி | உறுப்பு | செயல் |
|----|--------|-------|
| 1 | பக்கத் தலைப்பு | ஆலை மேலாண்மை முகப்பு எனக் காட்டும் |
| 2 | பச்சை மின்னும் புள்ளி | தரவு நேரலையாக வருவதன் அடையாளம் (LIVE) |
| 3 | தங்க நிற அட்டை | மொத்த விற்பனைத் தொகை (₹) + அனுப்பிய இன்வாய்ஸ் எண்ணிக்கை |
| 4 | பச்சை அட்டை | இதுவரை அனுப்பிய மொத்தத் துணி அளவு (மீட்டர்) |
| 5 | நீல அட்டை | நெசவுத் தறிகளின் சராசரி செயல்திறன் (OEE %) |
| 6 | ஊதா அட்டை | மறுசுழற்சி செய்யப்பட்ட தண்ணீர் சதவீதம் |
| 7 | வரைபடம் 1 | தறிகளின் வார செயல்திறன் வரைபடம் |
| 8 | வரைபடம் 2 | கொதிகலத்தின் (பாய்லர்) நீராவிப் பயன்பாட்டு வரைபடம் |
| 9 | வரைபடம் 3 | மாதாந்திரத் துணி உற்பத்தி அளவுக் கோடுகள் |
| 10 | வரைபடம் 4 | இருப்பு குறைந்த துணிகள் — சிவப்பில் எச்சரிக்கை ("35 மீ மட்டுமே") |
| 11 | தானியங்கு புதுப்பிப்பு | 30 வினாடிக்கு ஒருமுறை எண்கள் தானாகப் புதுப்பிக்கும் |

| மணி ஐகான் | புதிய எச்சரிக்கைகளின் எண்ணிக்கை — அழுத்தினால் பட்டியல் |
| எச்சரிக்கை உருப்படி | அழுத்தினால் சம்பந்தப்பட்ட பக்கத்துக்குச் செல்லும் |

| புரொஃபைல் | உள்நுழைந்தவரின் பெயரும் பதவியும் |
| பக்கவாட்டு மெனு | ஒவ்வொரு துறையின் பக்கமும் — அழுத்தினால் அந்தப் பகுதி திறக்கும் |
| Logout | வெளியேறி மீண்டும் உள்நுழைவுப் பக்கத்துக்குச் செல்லும் |

## 🎯 ஒரு வரி சுருக்கம்

```
ஊழியர் உள்நுழைவு / புதிய கணக்கு → சர்வர் சரிபார்ப்பு
→ டாஷ்போர்டு (நேரலை எண்கள்) → பக்கவாட்டு மெனுவில் துறை தேர்வு
→ வேலை → நேரலை எச்சரிக்கைகள் → வெளியேறு
```

**எல்லா எண்களும் தரவுத்தளத்திலிருந்து (MySQL) நேரலையாக வருகின்றன — எதுவும் நிலையானதல்ல.**
