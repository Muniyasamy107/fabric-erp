# 🎨 CAD Weave Design — வரி வரியாக முழு விளக்கம்

## முதலில்: Weave Architecture Pattern என்றால் என்ன?

துணி = **பாவு நூல் (நீள வாக்கு)** × **ஊடு நூல் (குறுக்கு)** இழைகளின் குறுக்கீடு.
"எந்த நூலை, எந்த வரிசையில் மேலே உயர்த்திப் பின்ன வேண்டும்" என்பதன் விதிமுறையே
**Weave Architecture** — அதாவது துணியின் **மாதிரி (pattern) வரைபடம்**.
வீட்டுக்கு ப்ளூ-பிரின்ட் போல, துணிக்கு இது தான் அடிப்படை வரைபடம்.

இதனால் தான் துணியில் கோடு, கட்டம், மின்னல், ஜிக்-ஜாக் போன்ற தோற்றங்கள் வருகின்றன.

### நமது 4 விருப்பங்கள் — நிஜ உதாரணத்துடன்

| விருப்பம் | தோற்றம் | எங்கே பார்த்திருப்பீர்கள் |
|----------|---------|---------------------------|
| **Herringbone Pointed Twill** | "மீன் எலும்பு" V-ஜிக்ஜாக் — கோடு வலது பக்கம் போய், திரும்பி இடது பக்கம் போகும் | சூட் / கோட் துணி |
| **Satin Pinstripe Damask** | மின்னும் மென்மை + மெல்லிய கோடுகள் | ஃபார்மல் சட்டை |
| **Glen Plaid (Prince of Wales) Check** | சிறிய + பெரிய கட்டங்கள் கலந்த கோலம் | ப்ளேசர் / சூட் |
| **Dobby Geometric** | சிறிய சிறிய வடிவங்கள் (டைமண்ட், புள்ளி) திரும்பத் திரும்ப | டிசைன் சட்டை |

## Modal-ல் ஒவ்வொரு வரியும்

### வரி 1
- **Concept Design Name** — புது டிசைனின் பெயர். எ.கா. `Imperial Silk Herringbone Twill`
- **Target Buyer / Fashion House** — எந்த வாடிக்கையாளருக்கு. எ.கா. `Armani Group Milan`

### வரி 2
- **Weave Architecture Pattern** — மேலே உள்ள 4-ல் ஒன்றைத் தேர்வு (துணியின் தோற்ற முடிவு!)
- **Season Collection** — எந்த சீசன் கலெக்ஷன். எ.கா. `Fall/Winter Milano 2026`

### வரி 3 — Dobby Loom Construction (EPI × PPI)
- **Heald Shafts** — நூலை உயர்த்தும் பிரேம்களின் எண்ணிக்கை.
  - 2 = சாதா துணி · 4 = twill · 8–16 = சிக்கலான டிசைன்.
  - **எண் கூடக் கூட டிசைன் சிக்கலாகும்.**
- **Warp Density (EPI)** — ஒரு அங்குலத்தில் நீள நூல்கள். `110` = அங்குலத்துக்கு 110 நூல்கள் = நுண்ணிய, அடர்த்தியான துணி.
- **Weft Density (PPI)** — ஒரு அங்குலத்தில் குறுக்கு நூல்கள். `84`.

### வரி 4
- **Sample Yardage (Meters)** — மாதிரிக்கு எவ்வளவு மீட்டர் நெய்ய வேண்டும். `10` — buyer மாதிரியைப் பார்த்துத் தான் பெரிய ஆர்டர் தரும்!
- **Lead CAD Designer** — டிசைனர் பெயர். எ.கா. `Ananya (NIFT)`

### பொத்தான்கள்
- **Cancel** — சேமிக்காமல் மூடு.
- **Initialize Sample Development** — டிசைன் உருவாக்கு → **Design Code** (எ.கா. CAD-0007) கிடைக்கும்.

*(உள்ளே தானாக: warp yarn = Mulberry Silk Midnight Navy · weft = Cashmere Champagne Gold ·
color repeat = 48 நூல் Navy + 6 நூல் Gold... — இவை Tech Sheet-ல் தெரியும்.)*

## Save ஆன பின் என்ன?

1. Studio-வில் டிசைன் அட்டை வரும்.
2. **Tech Sheet Print** — மாதிரி அறைக்கு முழு வரைபடம்:
   weave structure, shafts, EPI/PPI, **Total Construction (EPI×PPI)**, yarn விவரம், designer, buyer.
3. மாதிரி நெய்து → buyer ஒப்புதல் → பிறகு **Production Planning**-ல் பெரிய ஆர்டர்!

**Flow:** CAD டிசைன் → மாதிரி → buyer ஒப்புதல் → பெரிய உற்பத்தி 🏭
