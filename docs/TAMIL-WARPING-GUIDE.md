# 💿 Warping & Sizing — வரி வரியாக முழு விளக்கம்

**Page தலைப்பு:** Warping Creel, Sizing & Weaver's Beam Bank

**இது என்ன?** நெசவுக்கு முந்தைய தயாரிப்பு நிலை.
- **Warping** = நூற்றக்கணக்கான yarn cone-களிலிருந்து நூல்களை இணையாக எடுத்து
  ஒரு பெரிய உருளை (beam) மீது சுற்றுதல்.
- **Sizing** = அந்த நூல்களுக்கு மாவு (starch/PVA) பூசி **வலிமை** கொடுத்தல் —
  இது இல்லையென்றால் தறியில் நூல் அறுந்துவிடும்!
- **Beam** = ஆயிரம் நூல்கள் இணையாகச் சுற்றப்பட்ட பெரிய உருளை — தறியின் "எரிபொருள் டேங்க்"!

**உவமை:** சடை பின்னும் முன் முடியைச் சீவி, எண்ணெய் போட்டு வலுப்படுத்துவது போல! 💇

## Modal — வரி வரியாக

### வரி 1 (இரண்டு dropdown)
1. **Target Woven Fabric Quality** — எந்தத் துணிக்கு இந்த beam (catalog-ல் இருந்து தேர்வு; code தானாக)
2. **Source Yarn Cone Lot (Creel Supply)** — எந்த நூல் lot-லிருந்து எடுக்க வேண்டும் (yarn store-ல் இருந்து; spec தானாக)

### வரி 2 (மூன்று எண்கள்)
3. **Total Warp Ends (Threads)** — beam-ல் சுற்ற வேண்டிய மொத்த நூல்கள் `4800` (4800 நூல்கள் இணையாக!)
4. **Warp Wound Length (Meters)** — எவ்வளவு நீளம் சுற்ற வேண்டும் `1500 m`
5. **Beam Flange Width (Inches)** — beam-ன் பக்கத் தட்டு அகலம் `68"` (நாடா சுற்றும் உருளையின் இரு பக்கம்)

### Sizing Machine பகுதி
6. **Starch / Sizing Chemical Recipe** — மாவுக் கலவை: `Maize Starch (8%) + PVA Binder + Wax Emulsion`
   (மக்காச்சோளை மாவு + PVA பசை + மெழுகு — நூல் வலிமை + வழவழப்பு)
7. **Size Pick-up (%)** — நூல் எடையில் எவ்வளவு % மாவு ஒட்டியது `8.5%`
8. **Residual Moisture (%)** — உலர்த்திய பின் மீதம் உள்ள ஈரம் `6.5%`
   (மிக வறண்டு = நூல் உடையும் · மிக ஈரம் = பூஞ்சை!)
9. **Drying Cyl Temp (°C)** — உலர்த்தும் உருளை வெப்பம் `115°C`

### வரி 3
10. **Allocate to Weaving Loom** — இந்த beam எந்தத் தறிக்கு (dropdown) `LOOM-A01`
11. **Warping Master / In-Charge** — பொறுப்பாளர் `Warping Master Arumugam`

**Save** → Beam Code (WB-xxx) alert.
