# 🧮 Fabric Costing & BOM — வரி வரியாக முழு விளக்கம்

**தலைப்பு:** Fabric Cost of Production (COP) & BOM Costing
**BOM = Bill of Materials** — செலவு உருப்படிகளின் பட்டியல்.
**COP = Cost of Production** — ஒரு மீட்டர் துணி உற்பத்திக்கு ஆகும் மொத்தச் செலவு.
**Ex-Mill Price** = ஆலை வாயிலில் விற்கும் விலை (செலவு + லாபம்).

**உவமை:** வீட்ல தோசை — அரிசி செலவு + பருப்பு + கேஸ் + உழைப்பு = மொத்த செலவு;
அதோட மேல லாபம் சேர்த்தா = விற்கும் விலை! 🥞
