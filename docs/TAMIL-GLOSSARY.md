# 📖 துணி ஆலை சொற்கள் அகராதி (தமிழில்)

ஆலையில் பயன்படும் முக்கிய சொற்களின் எளிய தமிழ் விளக்கம்.

| சொல் | முழு விளக்கம் | எளிய தமிழ் |
|------|----------------|------------|
| **GSM** | Grams per Square Meter | ஒரு சதுர மீட்டர் துணியின் எடை (கிராம்) — துணியின் தடிமன்/கனம் அளவு |
| **தறி (Loom)** | Weaving machine | நூலைத் துணியாக நெய்யும் இயந்திரம் |
| **நூல் (Yarn)** | Spun thread | துணி நெய்யப் பயன்படும் இழை |
| **பாவு நூல் (Warp)** | Lengthwise yarn | துணியின் நீள வாக்கில் இருக்கும் நூல்கள் |
| **ஊடு நூல் (Weft)** | Crosswise yarn | குறுக்காகப் பின்னப்படும் நூல்கள் |
| **EPI** | Ends Per Inch | ஒரு அங்குலத்தில் பாவு நூல்களின் எண்ணிக்கை — அடர்த்தி |
| **PPI** | Picks Per Inch | ஒரு அங்குலத்தில் ஊடு நூல்களின் எண்ணிக்கை |
| **கச்சா துணி (Greige)** | Unfinished fabric | சாயம்/பினிஷிங் ஆகாத நெய்த துணி |
| **சாயம் ஏற்றுதல் (Dyeing)** | Coloring | துணிக்கு நிறம் கொடுக்கும் செயல்முறை |
| **மாவு ஏற்றுதல் (Sizing)** | Starching warp | பாவு நூலுக்கு வலிமை தர மாவு பூசுதல் |
| **சுருக்கம் (Shrinkage)** | Shrink % | துவைத்த பின் துணி சுருங்கும் சதவீதம் |
| **நிற உறுதி (Fastness)** | Color fastness | நிறம் மங்காமல் இருக்கும் திறன் |
| **பேல் (Bale)** | Compressed pack | ஏற்றுமதிக்கு அழுத்திக் கட்டப்பட்ட துணி மூட்டை |
| **தொகுதி (Lot)** | Batch | ஒன்றாகத் தயாரிக்கப்பட்ட துணிக் குழு |
| **OEE** | Overall Equipment Effectiveness | இயந்திரத்தின் மொத்த செயல்திறன் சதவீதம் |
| **பாவு அறுப்பு (Warp break)** | Warp yarn break | நெசவின்போது பாவு நூல் அறுதல் — தறி நின்றுவிடும் |
| **இன்வாய்ஸ் (Invoice)** | Bill | விற்பனை விலைப்பட்டியல் |
| **சதுர மீட்டர்** | Square meter | 1 மீட்டர் நீளம் × 1 மீட்டர் அகலம் பரப்பு |

## GSM எடுத்துக்காட்டுகள்

| துணி | GSM | தன்மை |
|------|-----|--------|
| வாயில் / கேம்ப்ரிக் | 60–90 | மெல்லிய, இலேசான — கோடை சட்டை |
| பாப்ளின் | 100–140 | நடுத்தர — சட்டை, யூனிஃபார்ம் |
| ட்வில் | 150–220 | சற்று கனம் — பேண்ட் |
| டெனிம் | 300–400 | கனமான, உறுதி — ஜீன்ஸ் |
| கேன்வாஸ் | 350+ | மிகக் கனம் — பை, கூடாரம் |

**நினைவில் கொள்க:** GSM கூடக் கூட துணி கனமாகவும் உறுதியாகவும் இருக்கும்;
GSM குறையக் குறைய துணி மெல்லியதாகவும் இலேசாகவும் இருக்கும்.
